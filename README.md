## 怎么编译运行

需要 gcc 编译器。每个 `.c` 文件都可以单独编译：

```bash
gcc -Wall -o hello hello.c
./hello
```

如果装了 VS Code，直接打开本文件夹，按 `Ctrl+Shift+B` 编译，或按 `F5` 调试。

## 我学到了什么

**环境搭建**：编译器（gcc）和编辑器（VS Code）是两回事，编辑器不负责编译，只是调用编译器。

**为什么 .exe 不进仓库**：它是编译产物，同一份 `.c` 源码在任何电脑上都能重新编译出来，把二进制文件传上去只会让仓库变臃肿。

**Git 的三个区域**：工作区（改文件）→ 暂存区（`git add`）→ 版本库（`git commit`）。
