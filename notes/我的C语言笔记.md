## 变量与数据类型

### 一句话
变量是一个"贴了标签的盒子"，类型决定这个盒子能装什么样的数。
（用你自己的话写，**不要抄课件**。）

### 我的代码（必须亲手跑过）
```c
#include <stdio.h>

int main(void)
{
    int price = 100;              /* 整数 */
    double rate = 0.85;           /* 小数 */
    char grade = 'A';             /* 单个字符，注意是单引号 */

    printf("price = %d\n", price);
    printf("rate  = %f\n", rate);
    printf("grade = %c\n", grade);
    return 0;
}
```

**运行结果**（把你实际看到的输出贴在这里）：
```
price = 100
rate  = 0.850000
grade = A
```

### 关键点
- `%d` 对应 int，`%f` 对应 float/double，`%c` 对应 char —— **格式符和类型必须匹配**
- 字符用**单引号** `'A'`，字符串用**双引号** `"A"` —— 这两个搞混是新手常见错误

## 输入输出

### 一句话
`printf` 把数据送到屏幕，`scanf` 从键盘把数据读进变量。

### 我的代码
```c
#include <stdio.h>

int main(void)
{
    int a, b;
    printf("请输入两个整数（用空格隔开）：");
    scanf("%d %d", &a, &b);      /* 注意每个变量前面都要加 & */
    printf("%d + %d = %d\n", a, b, a + b);
    return 0;
}
```

### 我踩的坑
- **scanf 里忘记写 `&`** → 程序可能崩溃或读出乱码。我犯过 ___ 次。
- 我原来以为「定义变量时不能用表达式初始化」，实测发现**可以**（Dev-C++ 默认模式编译通过）。
  严格 C89 模式下才会报错：`ISO C90 forbids mixed declarations and code`。

### #1 忘记加 &
- 日期：2026-10-__ 
- 报错：程序运行时崩溃 / 输出奇怪的数字
- 根因：`scanf("%d", a)` 少了 `&`，把变量的**值**当成了地址
- 修法：写成 `scanf("%d", &a)`
- 通用教训：**scanf 的参数必须是地址，所以基本都要加 &**
